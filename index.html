About the Research

Why Betel Leaf AI?

The Problem

Betel leaf production is affected by soil conditions, nutrients, moisture and weather. Understanding these factors together can be difficult for farmers.

Our Solution

We investigate machine learning, particularly XGBoost, to estimate betel leaf yield from relevant environmental and soil inputs.

Farmer-Centred Design

The proposed mobile application allows farmers to enter readings collected using suitable instruments instead of requiring permanently installed IoT sensors.

System Process

How It Works

  1. Collect: Gather soil, climate and nutrient readings.
  2. Validate: Check input values and measurement units.
  3. Prepare: Format data for the trained machine-learning model.
  4. Predict: Use XGBoost to estimate leaf count per bed.
  5. Present: Display the estimate and relevant guidance.
  6. Improve decisions: Help farmers interpret field conditions.
